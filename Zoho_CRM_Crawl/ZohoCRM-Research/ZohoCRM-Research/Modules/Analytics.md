# Module — Analytics (Dashboards + Zoho Analytics connector)

> Sources: https://help.zoho.com/portal/en/kb/crm/analytics-and-dashboards/analytics-dashboards/articles/create-dashboard ; https://www.zoho.com/analytics/help/connectors/zoho-crm.html

## AN.1 Dashboards in CRM

### Components (verbatim from official doc)

| Component | Description |
|---|---|
| KPI | single-number Headline KPI tile |
| Chart | tabular chart (multi-format) |
| Target Meter | gauge / progress vs target |
| Quadrant | x/y scatter with 4 quadrants |
| Zone | choropleth on a region map |
| Funnel | stage funnel |

Export as Excel/CSV (verbatim from the create-dashboard page): "The download as Excel/CSV option is supported for the following components: KPI, Chart, Target Meter, Quadrant, and Zone."

### Layout

- Grid layout with drag-resize tiles.

## AN.2 Zoho Analytics Connector (Optional Add-On)

https://www.zoho.com/analytics/help/connectors/zoho-crm.html :

> "The Advanced Analytics for Zoho CRM includes 100+ prebuilt reports and dashboards over your Zoho CRM data that help you to jump-start your analytics right away."

Features (https://www.zoho.com/analytics/whats-new/release-notes/previous-years.html ):

- Pivot tables
- Custom formulas
- Conditional formatting with Color and Icon Bands
- Drag-and-drop dashboards
- Merge tables across modules
